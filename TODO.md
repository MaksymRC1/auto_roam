# План дій на майбутнє (Future Roadmap)

Ми завершили етап створення повноцінного MVP (Minimum Viable Product). Система вміє будувати реальні маршрути, динамічно виявляти кордони, розраховувати витрати та знаходити готелі з прив'язкою до реальних міст. 

Ось план подальшого розвитку проекту (AutoRoam):

## Етап 1: PWA та Offline підтримка
Наразі проект ініціалізовано як PWA, але сервіс-воркери не налаштовані на офлайн.
- [ ] **Manifest & Icons:** Додати правильні іконки (512x512) для iOS та Android, налаштувати `manifest.json`.
- [ ] **Service Worker:** Налаштувати `next-pwa` або `serwist` для кешування статики (JS/CSS) та тайлів карти Leaflet. Це дозволить відкривати вже завантажений маршрут без інтернету під час поїздки.
- [ ] **Install Prompt:** Зробити красиву кнопку "Встановити додаток на телефон" у головному інтерфейсі.

## Етап 2: Покращення користувацького досвіду (UX/UI)
- [ ] **Drag & Drop Вейпоінти:** Дозволити користувачеві міняти порядок зупинок (наприклад, пересунути заправку або додати проміжне місто).
- [ ] **Збереження історії:** Використати `localStorage` або `IndexedDB` для збереження попередніх маршрутів (щоб не вводити їх заново).
- [ ] **Локалізація (i18n):** Додати підтримку англійської мови для ширшої аудиторії.

## Етап 3: Інтеграції з додатковими API
- [ ] **Ціни на пальне онлайн:** Замість ручного вводу ціни за літр, інтегрувати безкоштовні API для підтягування середньої ціни на пальне по країні (наприклад, актуальні ціни в Польщі чи Німеччині).
- [ ] **Черги на кордоні (Real-time):** Спарсити або інтегрувати API Державної прикордонної служби України для відображення реального часу очікування в годинах.
- [ ] **Погода на маршруті:** За допомогою безкоштовного OpenWeatherMap показувати прогноз погоди на точках зупинки відповідно до розрахункового часу прибуття.

## Етап 4: Монетизація та масштабування
- [ ] **Affiliate-програми:** Додати партнерські посилання не лише на Booking.com, але й на сервіси продажу онлайн-віньєток, страхування (Зелена карта).
- [ ] **Backend (опціонально):** Якщо потрібно буде зберігати акаунти користувачів і синхронізувати маршрути між ПК та телефоном — можна додати Firebase Authentication + Firestore (це безкоштовно для початку).
