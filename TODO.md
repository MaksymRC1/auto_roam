# План дій на майбутнє (Future Roadmap)

Ми завершили етап створення повноцінного MVP (Minimum Viable Product). Система вміє будувати реальні маршрути, динамічно виявляти кордони, розраховувати витрати та знаходити готелі з прив'язкою до реальних міст. 

Ось план подальшого розвитку проекту (AutoRoam):

## Етап 1: Технічний борг та Рефакторинг (Пріоритет)
- [x] **Виправлення гонок (Race conditions):** Забезпечити скасування старих запитів при швидкому введенні даних (зміна точок маршруту) в `useTripStore.ts`.
- [x] **Паралельне геокодування:** Замінити послідовні запити на `Promise.all` для геокодування міст зупинок, щоб прискорити розрахунок.
- [x] **Очищення коду:** Видалити дубльовані методи (наприклад, `setHotelOverride`), невикористовувані файли (`cargopedia.html`, `test-bdc.js`, тощо) та імпорти.
- [ ] **A11y (Доступність):** Додати `aria-hidden` до бекграундів, `role="list"` для таймлайну.
- [ ] **Оптимізація React:** Використати `useMemo` для підрахунку кошторису та оптимізувати рендер слайдшоу (тільки поточне та наступне фото).

## Етап 2: PWA та Offline підтримка
Наразі проект ініціалізовано як PWA, але сервіс-воркери не налаштовані на офлайн.
- [ ] **Manifest & Icons:** Додати правильні іконки (512x512) для iOS та Android, налаштувати `manifest.json`.
- [ ] **Service Worker:** Налаштувати `next-pwa` або `serwist` для кешування статики (JS/CSS) та тайлів карти Leaflet.
- [ ] **Install Prompt:** Зробити красиву кнопку "Встановити додаток на телефон" у головному інтерфейсі.

## Етап 3: Покращення користувацького досвіду (UX/UI)
- [x] **Панель палива:** Перенесення стану в глобальний store, додавання кількох країн для заправки.
- [x] **Слайдшоу та Інтерфейс:** Додано плавний анімований фон з фото різних країн, вирівняно пропорції екрану.
- [x] **Позначки Шенгену:** Показувати кордони з позначкою "Шенгенська зона — без контролю".
- [x] **Drag & Drop Вейпоінти:** Дозволити користувачеві міняти порядок зупинок.
- [ ] **Збереження історії:** Використати `localStorage` або `IndexedDB` для збереження маршрутів.
- [ ] **Локалізація (i18n):** Додати підтримку англійської мови.

## Етап 4: Інтеграції з додатковими API
- [ ] **Ціни на пальне онлайн:** Інтегрувати безкоштовні API для підтягування середньої ціни на пальне.
- [ ] **Черги на кордоні (Real-time):** Спарсити або інтегрувати API ДПСУ для відображення реального часу очікування.
- [ ] **Погода на маршруті:** Показувати прогноз погоди на точках зупинки відповідно до розрахункового часу прибуття (OpenWeatherMap).

## Етап 5: Монетизація та масштабування
- [x] **Affiliate-програми:** Партнерські посилання на сервіси продажу онлайн-віньєток, страхування (Hotline.Finance) та готелів (Stay22).
- [ ] **Backend (опціонально):** Firebase Authentication + Firestore для зберігання маршрутів користувачів.
