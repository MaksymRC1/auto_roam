# Desktop Layout Focus
Until the user explicitly states they are exiting the 'desktop version layout' phase, ONLY discuss and make changes to the desktop layout (typically handling `lg:`, `xl:`, or `2xl:` breakpoints). Ignore tablet-specific layout components (unless they share `lg:`) and mobile-specific layout components unless absolutely necessary for the desktop experience.
<!-- END:desktop-layout-rule -->
